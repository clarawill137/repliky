# 🗨 Реплики

Расширение для SillyTavern. Пост целиком пишет основная модель (Опус, GPT — с их эмоциональным интеллектом), а после него отдельная модель (по умолчанию **Аргон**) читает готовый пост и к каждой реплике выбранных персонажей пишет свои варианты. Это не перефразирование: варианты сказаны другими словами и с другого захода, но делают в сцене то же самое и обращены к тому же человеку. Поэтому текст вокруг (реакции, ответы, слова автора) остаётся верным.

- **В посте** реплики подчёркнуты пунктиром. Тап — шторка с вариантами, выбранный вариант встаёт прямо в сообщение. Изменённая реплика подчёркнута золотым, оригинал всегда можно вернуть. «↻ Ещё варианты» добавит новые к этой реплике.
- **Под постом** плашка «🗨 Варианты реплик · N»: все реплики поста сразу. Пока модель думает, на плашке крутится значок, если что-то не вышло — тап повторит.
- **Выбранное остаётся в истории**, поэтому основная модель дальше подтягивается к этому голосу.
- **Что знает модель:** карточку персонажа (описание и личность, без примеров диалогов), записи со ★ этого персонажа из лорбука голосов (по умолчанию «Hedy Bucky Psyche»: ядро и «★ Голос …»), несколько последних сообщений и сам пост. Образцы фраз из голоса нужны только для интонации, повторять их запрещено.
- **Персонажи:** отмечаются в настройках, по умолчанию включён только Баки. Реплики игрока не трогаются никогда.
- Плашки, теги, артефакты, дневник, компас и сообщения в телефоне не трогаются: реплики ищутся только в прозе.
- Работает само по себе, без Конвейера. В пульте Life появляется плиткой «Реплики» среди агентов.

## Установка

```
docker exec sillytavern sh -c 'cd /home/node/app/data/default-user/extensions && git clone https://github.com/clarawill137/repliky'
```
Потом перезагрузи таверну. В «Расширения → 🗨 Реплики» выбери профиль подключения с Аргоном (если в названии профиля есть «Argon» или «Аргон», он выберется сам).

Обновление:
```
docker exec sillytavern sh -c 'cd /home/node/app/data/default-user/extensions/repliky && git pull'
```

## Команды

- `/repliky` — варианты для последнего поста (заново).
- `/repliky 812` — для сообщения №812.
- `/repliky off`, `/repliky on` — выключить или включить расширение.

## Где что хранится

Варианты лежат в метаданных чата (`chat_metadata.repliky`, последние 150 постов). Ключ — время сообщения и номер свайпа, поэтому у каждого свайпа свои варианты. Когда реплика заменяется, Life об этом узнаёт (`LifeBridge.api.rekeyMessage`) и переносит запись Летописца на новый текст сообщения.
